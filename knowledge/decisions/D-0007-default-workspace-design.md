# D-0007: Default workspace launcher and contributor CI discipline

The user requested a default merging Obsidian workspace organization with
Riot/Steam-style game launcher hierarchy. Adopt Nocturne: a dark workspace rail,
flexible library, one original featured landscape and a clear example-launch
link. This supersedes D-0006's default-neutral stance for the shipped template;
the distinct-ui workflow and opt-in alternate industrial profile remain useful.
A future product brief can deliberately replace this default, without giving up
explicit geometry, state behavior and rendered verification.

Active semantic Tailwind tokens reset stock color/radius namespaces across all
shared routes. Use original local SVG artwork, system fonts and Trunk bundling;
no external account, image request, copied branding or new dependency is needed.
The default page is the library; #/ retains the response lab and all core/owner
cleanup behavior. No game installation/execution or real content/account service
is introduced. Preferences remain local demo state and native authority unchanged.

CI efficiency and idempotency become contributor/reviewer responsibilities for
every affected change: measure critical-path waste, make repeated setup converge,
verify pins/cached content, retain cold correctness and trusted cache boundaries,
and preserve functional/security coverage. Improve relevant waste within scope;
record larger opportunities rather than making speculative unrelated rewrites.
No review reasoning above standard/medium is authorized.

Alternatives: cinematic storefront sacrifices workspace navigation; pure dense
editor weakens the library/launch hierarchy. Both were considered in the brief.
Revisit when user tasks, brand needs, accessibility findings or measured workflow
costs justify another composition or CI mechanism.
